# 패치 05 — 다크 테마를 검정에서 회색으로

다크 테마 바탕이 사실상 검정(#121317)이라 무겁게 보였습니다. 차가운 회색 계열로 한 단계씩 올려, 바탕 위에 판이 얹힌 층이 눈에 보이게 했습니다. accent(#22D3EE)는 그대로입니다.

`src/UbisamBase.Core/Themes/Colors.Dark.xaml` **한 파일만** 교체하면 됩니다 — 이 프로젝트의 `code/UbisamBase.Core/Themes/Colors.Dark.xaml`을 그대로 복사하세요.

## 바뀐 값

| 역할 | 기존 | 변경 |
| --- | --- | --- |
| 컨텐츠 바탕 | #121317 | **#23262B** |
| 판 (상단바 · 하단 탭 · 서브탭) | #16171C | **#2A2E34** |
| 경계 | #2A2C33 | **#3A3F47** |
| 본문 글자 | #E6E6E9 | **#E8EAED** |
| 보조 글자 | #B8BCC4 | **#C2C7CE** |
| 흐린 글자 | #6A6F79 | **#8A9099** |
| accent 위 글자 | #0B0C0F | **#12161A** |
| 입력 배경 | #1B1D23 | **#2F343A** |
| 입력 경계 | #33363E | **#454B54** |
| 입력 경계 hover | #4A4E57 | **#5A616B** |
| 입력 비활성 배경 / 경계 | #191A1F / #26282F | **#292D32 / #383D44** |
| 표 헤더 배경 | #1B1D23 | **#2F343A** |
| 표 행 경계 | #1F2127 | **#383D44** |
| hover 틴트 | #22FFFFFF | **#16FFFFFF** (바탕이 밝아진 만큼 약하게) |

바탕(#23262B) → 판(#2A2E34) → 입력(#2F343A) → 표 헤더(#2F343A) 순으로 밝아지는 3단 층입니다. 층 순서를 지키면 값은 취향대로 조정해도 구조가 유지됩니다.

## 확인

1. 다크 테마에서 상단바·하단 탭이 컨텐츠 바탕과 구분되는지(판이 살짝 밝음)
2. 입력창이 판보다 한 단계 더 밝아 눌러 넣는 자리로 읽히는지
3. 시안 글자(#22D3EE)와 회색 바탕의 대비가 충분한지 — 더 진하게 하고 싶으면 accent를 #67E8F9로 올리면 됩니다
4. 로그 표의 행 경계선이 보이는지

## 더 밝게/어둡게 하려면

세 값만 같은 방향으로 움직이면 됩니다: `ContentBackground` / `Sidebar.Background`(= `SubTabBar.Background`) / `Input.Background`. 나머지 경계·글자는 그 위에서 자동으로 읽힙니다.

- 조금 더 밝게: #282C31 / #30343B / #363B42
- 조금 더 어둡게: #1D2024 / #24282D / #292E34
